# ACXA Technology — Landing Page

Landing page vitrine d'ACXA Technology : fond bleu nuit, tagline « L'innovation au service de la performance financière » et le A du logo en grand format illuminé avec vague de particules.

## Lancer en local

Aucune dépendance — site statique HTML/CSS/JS :

```bash
python3 -m http.server 8080
# puis ouvrir http://localhost:8080
```

## Structure

- `index.html` — page unique (nav, hero, features, footer)
- `css/style.css` — thème navy + A métallique illuminé (mask + drop-shadow)
- `js/main.js` — menu mobile + vague de particules (canvas)
- `assets/logo/` — déclinaisons du logo (mark A, lockup horizontal, wordmark, favicon)
